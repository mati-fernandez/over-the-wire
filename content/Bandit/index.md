# 🚩 OverTheWire: Bandit Writeups 
Welcome to my technical documentation for the Bandit wargame. This series focuses on Linux fundamentals, CLI proficiency, and basic security concepts. 
## 🛠️ Tools & Shortcuts
- **Official Instructions:** [overthewire.org/wargames/bandit](https://overthewire.org/wargames/bandit)
- **Fast Access:** `otw` (Alias configured in `.bashrc`)
- **Clipboard Utility:** `getpass` (Custom script to copy passwords)
- **SSH Connection:** `ssh banditX@bandit.labs.overthewire.org -p 2220`
